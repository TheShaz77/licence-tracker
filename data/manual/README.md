# Files you download yourself

A few registers block automated downloads (or ask robots not to download them).
For those, download the file in your browser and upload it here with the name
below. The tracker reads it on the next run and alerts on changes as usual;
upload a fresh copy whenever the register updates.

| File name | Where to get it | How often it changes |
|---|---|---|
| `fincen.xlsx` (or .xls/.csv/.txt) | msb.fincen.gov → MSB Registrant Search → search all states → Download | weekly |
| `us_ma.xlsx` | mass.gov → "Download a list of approved licensees" → Money transmitter licensee list | quarterly |
| `us_ak.pdf` | commerce.alaska.gov → Division of Banking & Securities → Money Service Businesses → MSB Licensee List | a few times a year |
| `za_tppp.pdf` | resbank.co.za → What we do → Payments and settlements → Regulation → public register of third-party payment providers | every few months |
| `za_so.pdf` | same page → public register of system operators | every few months |
| `za_pchso.pdf` | same page → public register of PCH system operators | every few months |
| `za_banks_locally.pdf`, `za_banks_foreign.pdf`, `za_banks_branches.pdf`, `za_banks_mutual.pdf` | resbank.co.za → Prudential regulation → SA registered banks and representative offices (Locally controlled banks, Foreign controlled banks, Branches of foreign banks, Mutual banks) | a few times a year |
| `za_casp.pdf` (or .xlsx) | fsca.co.za → news item "list of currently approved crypto asset service providers" → the list | only needed if the automatic link stops working |

The South African Reserve Bank's robots.txt asks automated tools not to download
its PDFs, so those lists only update when you upload a new copy here.
