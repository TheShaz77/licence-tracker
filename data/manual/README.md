# Files you download yourself

A few registers block automated downloads (or ask robots not to download them).
For those, download the file in your browser and upload it here with the name
below. The tracker reads it on the next run and alerts on changes as usual;
upload a fresh copy whenever the register updates.

| File name | Where to get it | How often it changes |
|---|---|---|
| `fincen.xlsx` (or .xls/.csv/.txt) | msb.fincen.gov → MSB Registrant Search → search all states → Download | weekly |
| `us_ma.xlsx` | mass.gov → "Download a list of approved licensees" → Money transmitter licensee list | quarterly |
| `us_ak.pdf` | commerce.alaska.gov → Division of Banking & Securities → Money Service Businesses → MSB Licensee List | a few times a year |
